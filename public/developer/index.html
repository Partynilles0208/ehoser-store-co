Schnellstart

Basis-URL: https://ehoser.de/api/v1

GET/status
Testet, ob der API-Schlüssel gültig ist und welche Rechte er hat.
POST/ai/chat
Verbessert Texte oder nutzt KI-Chat mit messages.
curl https://ehoser.de/api/v1/ai/chat \
  -H "x-api-key: EHOSER_DEIN_SCHLUESSEL" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Verbessere: ich esse grot"}]}'

Deine Schlüssel

Geheimnisse werden nie erneut angezeigt.

So funktioniert es

1Projekt anlegen
Zum Beispiel „Meine Website“ oder „Bot-Server“.
2Schlüssel nur einmal kopieren
Lege ihn als Umgebungsvariable auf deinem Server ab.
3Anfrage vom Server senden
Dein Browser spricht nur mit deinem Server – der Schlüssel bleibt geheim.
