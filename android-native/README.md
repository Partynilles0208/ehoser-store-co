# ehoser Chat für Android

Die Android-App öffnet direkt den mobilen ehoser Chat unter `https://www.ehoser.de/chat/`.
Sie nutzt denselben Account und dieselben Chatdaten wie die Website.

## Enthalten

- vollständige Touch-Ansicht für Handy und Tablet
- Anrufe und Videoanrufe mit Android-Kamera- und Mikrofonfreigabe
- Kamerwechsel während Videoanrufen
- Dateiauswahl, Downloads und gespeicherte Anmeldung
- Android-Benachrichtigungen für Nachrichten und eingehende Anrufe
- Zurück-Taste schließt zuerst Chatansichten oder Fenster statt die App sofort zu beenden

## APK bauen

Öffne `android-native` in Android Studio und starte `assembleDebug`, oder nutze den
GitHub-Actions-Workflow **Android APK**. Das Ergebnis ist eine installierbare Debug-APK.
